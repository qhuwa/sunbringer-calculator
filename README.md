# 绝区零配队伤害计算器

选择挽昼、猫又、零号·安比、叶瞬光或仪玄作为主 C，自由搭配两位队友。页面按所填技能轴计算单轮期望伤害，可调整影画、音擎、敌人和各技能乘区。

## 使用

在 [GitHub Releases](https://github.com/qhuwa/sunbringer-calculator/releases) 下载源码 ZIP，解压后用浏览器打开 `index.html`。角色与配装选择保存在当前浏览器。

- **对比配队。** 可用全 01 或手动配置作为基线。整队估算为主 C 伤害 ×（1＋系数一＋系数二）。
- **优化驱动。** 可锁定套装、主属性或指定副词条数，再搜索其余配置。
- **查看伤害来源。** 展开招式明细和技能乘区，可查看伤害占比、追加次数与乘区数值。页面底部列有代理人增益、公式和数据来源。

基于 GachaBase 与 Nanoka 的资料快照。测试服数据与实际战斗中的增益覆盖时间可能随版本和操作变化。
