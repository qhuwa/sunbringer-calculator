# 绝区零配队伤害计算器

用自己设定的技能轴估算一轮期望伤害。你可以比较不同队友、影画和音擎，按词条预算搜索驱动盘配装，也可以追溯每一招的伤害占比和增益来源。

## 开始使用

从发布页下载 **Source code (zip)**，解压后用浏览器打开 `index.html`。角色和配装选择会保存在当前浏览器。[下载计算器](https://github.com/qhuwa/sunbringer-calculator/releases/latest)

1. 在「队伍配置」选择主 C 和两名队友，设置影画、音擎与队伍增益。队友栏选「空气」可留空。
2. 在「战斗条件」选择 Boss、失衡状态、危局增益和区域效果。需要模拟其他敌人时，选择自定义敌人并填写防御和抗性。
3. 展开「招式明细」，用默认技能轴试算，或修改各招出手次数。页面顶部会显示本轮期望伤害和相对基线的结果。

## 比较队伍与配装

- **同一套驱动比队友。** 先点「整套锁定」，再点「设当前配置为基线」，然后换队友。顶部会显示相对刚才那套阵容的伤害变化。整套锁定按主 C 保存。
- **按队伍找最优驱动。** 输入有效副词条预算与各项上限。可以单独锁定四件套、两件套、主属性或指定副词条数。换队友时会自动寻优，也可以手动点「自动计算最优分配」。结果列出六张驱动盘的建议分配。
- **比较养成收益。** 在「配置对照」选择主 C 或队友的影画、音擎星级、音擎与驱动组合。主 C 影画表列出相对 0 影和上一影的提升。「每词条伤害提升」可查看当前配装下单条属性的收益。

默认「全 01」基线以当前出战成员均为 0 影、1 星专武计算。要查看自己现有配装的提升，可用手动基线。

## 读懂伤害数字

- **单轮期望伤害** 取决于招式次数和选定的失衡、增益覆盖、触发条件。队友卡片会列出当前生效的增益。招式明细会标出琉音、诺姆等队友带来的追加次数。
- **全队估算伤害** = 主 C 单轮期望伤害 ×（1＋队友 1 系数＋队友 2 系数）。两个系数都默认为 0，并按角色保存。比如填入 0.2 和 0.3，估算总伤就是主 C 的 1.5 倍。
- **技能乘区** 可逐格覆盖倍率，清空单格即可恢复自动值。「公式、条件与数据来源」提供终结技拆解，可核对面板属性、队友增益、防御、抗性和失衡等来源。

## 计算口径

- 技能和音擎描述中的「对目标造成的伤害提升」计入普通增伤，与属性和招式增伤相加。失衡易伤、锐化伤害、贯穿伤害和关卡受伤各自结算。
- 命破角色按战斗攻击力的 30% 转为贯穿力，队友提供的战斗攻击力也参与转换。贯穿增伤单独计乘区。

角色、音擎、驱动盘和 Boss 数值采用 GachaBase 数据快照，危局增益参考 Nanoka。各角色的倍率、触发假设和来源链接可在页面底部查阅。[GachaBase](https://zzz.gachabase.net/) · [Nanoka 危局强袭战](https://zzz.nanoka.cc/boss)

## 项目结构

- `index.html` 是网页入口，`ui/` 管理交互、样式和公式说明。
- `characters/` 收录代理人、技能轴与专属音擎，`engine/` 负责伤害结算、队伍增益和驱动盘寻优。
- `data/` 收录 Boss 与危局数据快照，`assets/` 存放页面资源。
