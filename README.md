# 绝区零配队伤害计算器

支持 23 位主 C，包括可琳、真斗、雨果、伊芙琳、11 号、朱鸢、艾莲、悠真和比利。队友可自由搭配，包括青衣、凯撒和希希芙。页面按所填技能轴计算单轮期望伤害，可调整影画、音擎、敌人和各技能乘区。

## 使用

在 [GitHub Releases](https://github.com/qhuwa/sunbringer-calculator/releases) 下载源码 ZIP，解压后用浏览器打开 `index.html`。角色与配装选择保存在当前浏览器。

- **对比配队。** 可用全 01 或手动配置作为基线。整队估算为主 C 伤害 ×（1＋系数一＋系数二）。
- **优化驱动。** 换队友时自动寻优，遵守各项锁定和词条上限。可锁定整套配装，用相同驱动盘比较队友。锁定状态按主 C 保存。
- **查看伤害来源。** 展开招式明细和技能乘区，可查看伤害占比、追加次数与乘区数值。页面底部列有代理人增益、公式和数据来源。

基于 GachaBase 与 Nanoka 的资料快照。测试服数据与实际战斗中的增益覆盖时间可能随版本和操作变化。

## 计算口径与项目目录

角色技能或音擎提供的「对目标造成的伤害提升」与普通、属性和招式增伤相加。例如潘引壶气绝、妮可聚宝箱与琉音二影。明确的失衡易伤、锐化伤害、贯穿伤害和关卡受伤仍按各自公式结算。命破角色将战斗攻击力的 30% 转为贯穿力，包含战斗中的固定和百分比攻击力加成。贯穿增伤以独立乘区结算，可在技能乘区里查看或覆盖。命破角色在旧版本保存的手动基线需要重新固定。

- `characters/` 收录代理人、技能轴、专属音擎及特性。
- `engine/` 存放伤害结算、队伍增益和驱动盘分配。
- `data/` 存放首领与危局快照。
- `ui/` 存放界面、设置和公式说明。
- `assets/` 存放本地页面资源。
